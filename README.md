# 이슈피클: 나만의 이슈 순위 사이트

30분마다 뉴스·검색어·영상을 자동으로 모아 한 화면에 보여주는 실시간 이슈 사이트예요.

| 섹션 | 데이터 출처 | 준비물 |
|---|---|---|
| 지금 뜨는 이슈 (1~20위, 온도) | 구글 뉴스 | 없음 |
| 치고 올라오는 이슈 | 구글 뉴스 (최근 2시간 기사 증가) | 없음 |
| 이슈人 (인물 언급 순위) | 구글 뉴스 제목 속 인물 이름 | 없음 |
| 분야별 이슈 (정치·경제·사회·연예·스포츠·IT·과학·세계) | 구글 뉴스 분야별 | 없음 |
| 검색 급상승 | 구글 트렌드 | 없음 |
| 지금 뜨는 영상 | YouTube | 무료 API 키 (5단계) |
| 콘텐츠 랭킹 › 유튜브 TOP 100 (분야별) | YouTube | 같은 키 (5단계) |
| 콘텐츠 랭킹 › 박스오피스 | 영화진흥위원회 | 무료 API 키 (6단계) |
| 콘텐츠 랭킹 › 넷플릭스 TOP 10 | 넷플릭스 공식 주간 순위 | 없음 |

화면 밝기(밝게/편하게/어둡게)와 글자 크기 조절도 들어 있어요.
서버나 유료 서비스 없이 **GitHub 하나로 무료 운영**할 수 있어요. (도메인 구입만 선택 사항)

> 처음 설정은 **PC에서** 하시는 걸 추천해요. 한 번 설정하면 그 뒤로는 자동으로 돌아가요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `collect.py` | 뉴스를 모아 순위를 계산하는 프로그램 |
| `.github/workflows/update.yml` | 30분마다 `collect.py` 를 실행하고 사이트를 갱신하는 자동 설정 |
| `site/index.html` | 사이트 메인 화면 |
| `site/content.html` | 콘텐츠 랭킹 (유튜브 · 박스오피스 · 넷플릭스) |
| `site/data.json` | 수집 결과 (자동으로 바뀌니 건드리지 마세요) |
| `site/about.html`, `copyright.html`, `privacy.html`, `terms.html` | 소개·저작권 정책·개인정보처리방침·이용약관 (애드센스 승인에 필요) |
| `site/ads.txt` | 애드센스 인증 파일 |

## 1단계: 사이트 올리기 (약 15분)

1. **GitHub 가입**: https://github.com 에서 무료로 가입해요.
2. **저장소 만들기**: 오른쪽 위 `+` → `New repository`
   - Repository name: `issue-radar` (원하는 이름)
   - **Public** 선택 (무료로 쓰려면 공개여야 해요)
   - `Create repository` 클릭
3. **파일 올리기**: 저장소 화면에서 `uploading an existing file` 클릭 → 압축을 푼 폴더 안의 내용(`collect.py`, `README.md`, `site` 폴더)을 끌어다 놓기 → `Commit changes`
4. **자동 설정 파일 만들기**: `.github` 폴더는 숨김 폴더라 업로드가 안 될 수 있어요. 그래서 직접 만들어요.
   - `Add file` → `Create new file`
   - 파일 이름 칸에 정확히 `.github/workflows/update.yml` 입력
   - 내용 칸에 `update.yml` 파일 내용을 전부 복사해 붙여넣기 → `Commit changes`
5. **사이트 켜기**: `Settings` → 왼쪽 `Pages` → **Source** 를 `GitHub Actions` 로 선택
6. **첫 실행**: 위쪽 `Actions` 탭 → `이슈 자동 수집` → `Run workflow` 버튼
   - 1~2분 뒤 초록색 체크가 뜨면 성공!
   - 사이트 주소: `https://내아이디.github.io/issue-radar/`

이제 30분마다 저절로 갱신돼요. 🎉

> 빨간 X가 뜨면 그 줄을 눌러 오류 메시지를 확인하세요. 대부분 4번 파일 이름 오타거나 5번 설정이 빠진 경우예요.

## 2단계: 내 것으로 꾸미기

- **사이트 이름**: `site/` 안의 html 파일들에서 `이슈피클` 을 원하는 이름으로 바꾸기
- **문의 이메일**: 스팸 방지를 위해 주소를 거꾸로 적어 숨겨 두었어요 (`data-u`, `data-d`). 바꾸고 싶으면 Claude에게 부탁하세요.
- **이슈人에 엉뚱한 단어가 뜰 때**: `collect.py` 의 `NOT_PEOPLE` 에 추가 / 빠진 인물은 `PEOPLE_EXTRA` 에 추가
- **분야 바꾸기**: `collect.py` 의 `CATEGORIES` 에서 줄을 지우거나 추가 (화면은 자동 반영)
- **이상한 키워드가 순위에 뜰 때**: `collect.py` 의 `STOPWORDS` 에 그 단어를 띄어쓰기로 추가
- **보여줄 이슈 개수**: `collect.py` 맨 위 `TOP_N = 10` 숫자 바꾸기

GitHub 화면에서 파일을 열고 연필 아이콘(✏️)을 누르면 바로 수정할 수 있어요.

## 3단계: 내 도메인 연결 (선택, 연 1~2만 원)

애드센스는 `github.io` 주소보다 **내 도메인**일 때 훨씬 수월해요.

1. 가비아·후이즈 등에서 도메인 구입 (예: `myissue.kr`)
2. GitHub `Settings` → `Pages` → **Custom domain** 에 도메인 입력 → `Save`
3. 도메인 구입한 곳의 DNS 설정에 아래 추가 (GitHub 화면 안내도 같이 보세요)
   - `A` 레코드 4개: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` 레코드: `www` → `내아이디.github.io`
4. 연결되면 `Enforce HTTPS` 체크

## 4단계: 광고 연결

### 애드센스 신청 전에 준비할 것
뉴스 링크만 자동으로 모은 사이트는 **'가치가 별로 없는 콘텐츠'로 거절**되는 일이 많아요. 승인 확률을 높이려면:
- 내 도메인 연결 (3단계)
- 소개·개인정보처리방침·이용약관 페이지 (이미 들어 있어요)
- **직접 쓴 글** 추가: 예를 들어 '이번 주 이슈 정리', '경제 용어 풀이' 같은 글을 10~20개 정도
- 사이트를 몇 주 운영해 방문자가 조금 생긴 뒤 신청

### 애드센스 연결
1. https://adsense.google.com 가입 → 사이트 주소 등록
2. 받은 코드에서 `ca-pub-` 뒤의 숫자 16자리 확인
3. `site/index.html` 위쪽의 **[광고 설정 1]** 주석을 풀고 `ca-pub-0000000000000000` 을 내 번호로 바꾸기
4. `site/ads.txt` 의 두 번째 줄 `#` 을 지우고 `pub-0000000000000000` 을 내 번호로 바꾸기
5. 승인 후 애드센스에서 '광고 단위'를 만들고, 받은 코드를 **[광고 설정 2]**, **[광고 설정 3]**, **[광고 설정 4]** 자리의 `<div>` 안에 붙여넣기 (첫 이슈 목록 아래, 분야별 이슈 아래, 맨 아래)

## 5단계: '지금 뜨는 영상' 켜기 (무료, 약 10분)

키가 없어도 사이트는 잘 돌아가요. 영상 섹션만 숨겨져 있을 뿐이에요.

1. https://console.cloud.google.com 에 구글 계정으로 로그인 → 위쪽에서 **새 프로젝트** 만들기
2. 검색창에 `YouTube Data API v3` 검색 → **사용** 클릭
3. 왼쪽 메뉴 `사용자 인증 정보` → `+ 사용자 인증 정보 만들기` → **API 키** → 생성된 키 복사
4. GitHub 저장소 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Name: `YOUTUBE_API_KEY`
   - Secret: 복사한 키 붙여넣기 → `Add secret`
5. `Actions` 탭에서 `Run workflow` 한 번 실행

처음엔 '인기 영상' 순서로 나오고, 두 번째 수집(30분 뒤)부터는 **시간당 조회수가 가장 빨리 늘어난 순서**로 바뀌어요.
하루 무료 사용량(10,000) 중 하루 48번 정도만 쓰니 요금 걱정은 없어요.

> API 키는 비밀번호와 같아요. 파일에 직접 쓰지 말고 꼭 위의 Secret 에만 넣으세요.

## 6단계: 박스오피스 켜기 (무료, 약 10분)

1. https://www.kobis.or.kr/kobisopenapi 에 들어가 회원가입 후 로그인
2. 위 메뉴 `키 발급/관리` → `키 발급` → 사용 목적에 '개인 웹사이트 영화 순위 표시' 정도로 적고 발급
3. 발급된 키(영문+숫자 32자리) 복사
4. GitHub 저장소 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Name: `KOBIS_API_KEY`
   - Secret: 복사한 키 → `Add secret`

어제 하루 관객 수 기준 1~10위가 나와요. (오늘 집계는 다음 날 나와요)

## 7단계: 밈절임 교차 확인 (선택)

- **커뮤니티 추가**: `sources.txt` 에 `사이트 이름 | RSS 주소` 한 줄을 추가해요. 사이트가 직접 공개한 RSS만 넣어요.
- **네이버 검색량 확인**: https://developers.naver.com 에서 '애플리케이션 등록' → 사용 API에 **데이터랩(검색어 트렌드)** 선택 → 받은 Client ID / Client Secret 을
  GitHub Secrets 에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 으로 넣어요. (하루 무료 1,000회 중 약 20회만 써요)
