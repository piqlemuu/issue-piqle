# 분야별 주 매체 (언론사 공식 RSS)
#
# 분야를 정한 매체의 기사는 그 분야 이슈를 모을 때 같이 쓰이고,
# 원문 주소를 그대로 알 수 있어서 기사에 실린 대표 사진을 바로 가져와요.
# 분야를  -  로 둔 매체는 이슈 계산에는 안 쓰이고, 같은 제목 기사의 사진을 찾는 데만 쓰여요.
#
# 한 줄에 하나씩:  언론사 이름 | 분야 | RSS 주소
#   분야: 연예 · 스포츠 · 생활·경제 · 음식·카페 · 뷰티·패션 · 쇼핑·혜택 · 여행·공간 · 문화·여가 · IT·테크 · 시사 · -
# 맨 앞에 # 을 붙이면 그 줄은 쓰지 않아요.
# 언론사가 직접 공개한 RSS만 넣어요. 잘 되는지는 Actions 실행 기록의 '[언론사 RSS]' 줄에서 볼 수 있어요.
# 실패로 나오는 줄은 앞에 # 을 붙여 꺼 주세요.
#
